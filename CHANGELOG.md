# Changelog

Notable changes to the extension. Versions match `manifest.json` and the Chrome Web Store.

## 6.10

- First public source release.
- Redesigned popup in the black and blue brand, with better contrast.
- Store name and summary translated into 25 languages.
- Optional rating prompt after a successful backup.
- Smaller package: removed unused files.

## 6.9

- New logo, icons and store visuals.

## 6.x

- Least-privilege permissions: `activeTab` instead of standing host access; `downloads` is optional.
- Pro activation by License ID through RevenueCat, with offline-safe status caching.
- Chat Viewer with search, jump to date, starred messages, edit history and recycle bin.
- Export all backups as `.zip` and import them on another computer.
- PDF, HTML and TXT exports. Long Chat mode for months of history.
