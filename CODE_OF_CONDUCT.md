# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith and keep discussion about the work. Harassment, insults and personal attacks are not accepted in issues, pull requests or any other project space.

Report problems to [support@teamschatbackup.com](mailto:support@teamschatbackup.com). Reports are kept confidential. Maintainers may edit or remove content and block participants who break these rules.
